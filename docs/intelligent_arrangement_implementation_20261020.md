# 智能编曲实施与验收记录（2026-10-20）

## 交付范围

基于官方 v0.3.0 的整合树继续修复。普通语音、故事、音乐生成和无智能编曲计划的原编曲保持原调用路径。带智能编曲计划的作品从普通曲谱渲染入口返回智能编曲，后端拒绝绕过选源预检直接使用 SF2。

## 已落地的执行链

1. **统一诊断与绑定**：`arrangement.inspect` 检查乐器身份、真实 / AI 来源限制、文件、奏法、音高和力度层。错误含声部 ID、乐句、小节与 MIDI 音高；适用候选只来自实际可用库存。`arrangement.bindSource` 返回可撤销的编辑副本。替代乐器必须显式选择；锁定声部不会被重新绑定、套用乐队或重新规划覆盖。
2. **逐乐句写谱**：服务端分配身份、填充声部骨架；模型使用短声部标签写音符。每句独立使用实际来源的奏法、音高与力度层约束，单句失败重试并保留其他已校验乐句。可清除写谱进度重新生成。
3. **持久备料**：单项、批量和一键准备共用持久任务。成功子任务立即登记；取消 / 重启后可继续。健康本地音源不联网，损坏目录音源可修复并保留来源 ID。原三件音源目录与扩展 CC0 目录都支持该修复。
4. **AI 素材**：YuE2 传入该句 ABC 条件；ACE-Step 使用支持的参数并标成自由音频。缓存包含本句音符、速度、奏法及条件版本，并按模型区分；缺少条件记录的旧缓存不冒充新谱对应素材。生成后检查时长、静音、削波及可测起音偏差，保存试听审核状态。音频模型选择随工程保存。
5. **插件演奏**：VST3 在独立宿主内运行。保存音色时加载用户程序 / 预设或原生编辑器，关闭编辑器后实际检查发声。保存预设状态、插件哈希和可识别的音色包依赖。库内预设可重新打开编辑器及试听；修改后重新试听。整轨输入完整 MIDI、自然力度 / 微时差、音量表情、声像等控制信息。插件管理仍在设置。
6. **拼合与工程**：真实采样、AI 乐句与 VST 分轨按照同一曲谱时间基准进入时间线。保留原轨道、历史静音结果及手工轨道；旧修订或旧预设的后台结果不覆盖新编辑。工程保存准备好的素材、可编辑乐谱、轨道、插件预设和依赖清单，第三方程序 / 模型权重不打包。
7. **参考与导入演奏**：参考音频经官方 SheetSage2 扒谱，用户采用分析后再供规划 / 写谱参考；未分析时明确说明模型没有听到音频。用户演奏另建手工轨道。SheetSage2 仍需在设置按需安装。
8. **Ocho**：接入库存、逐句预检、绑定、规划、写谱、持久备料、任务查询和拼合工具；使用同一应用服务。网页搜索结果只是候选，不能作为已安装来源；任务启动不等于完成。
