# 官方 v0.4.1 适配与性能优化

## 范围

本轮将官方 v0.4.0 和 v0.4.1 累计改动合入定制版，版本为 0.4.1-preview.1。保留智能编曲、音源库、插件、局部备料、试听确认和 Ocho 诊断。没有追加新音色生成实验。

上游来源：https://github.com/leemysw/yovoice/releases/tag/v0.4.1 。v0.4.1 本身修复 macOS 更新校验；本次从旧基座升级还包含 v0.4.0 的歌词与性能功能。

## 卡顿根因与实现

1. **整库反复推送**：真实 SSE 回归以 1.14 MB 合成作品复现。旧版助手队列一次变化也重发 1,140,948 字节。采用官方逐字段增量协议，接收端合并变化及删除字段；回归中同类更新为 76 字节。首次加载仍需要完整状态。
2. **全界面跟随回复重绘**：Ocho 的实时文本、排队与导航使用官方独立订阅。非助手状态未变时，不更新应用状态。持久问答和作品变更仍正常推送，不能为了流畅丢掉工具结果。
3. **整库 JSON 深拷贝**：CPU profile 显示字符串 UTF-8 扫描及 JSON 编解码占主要时间。改为一处共享的容器深拷贝，复用不可变字符串，独立复制切片、映射、指针及插件状态字节。自由模型参数中的数值继续保持旧 JSON 路径的 float64 语义。
4. **隐藏页面和长音频**：保留官方首次访问挂载、隐藏播放器暂停波形工作、流式 WAV 峰值读取；定制智能编曲和音源库同样纳入首次访问挂载集合。官方 1,275 秒、约 245 MB WAV 用例验证边读边计算，避免一次性整段解码。

不通过删除历史、清空作品、取消采样校验或关闭 Ocho 来提高速度。定制状态投影继续隐藏插件二进制、后台任务完整作品和缓存乐谱，并保留音源健康状态。

## 测量方法和边界

- 合成快照基准使用 27 个作品及 27 个历史版本，每份含较长中文文本。优化前约 16.06 ms/op、7.28 MB/op；首轮优化后约 0.296 ms/op、0.122 MB/op。测量受机器负载影响，不等于每个按钮加速相同比例。
- 真实库的隔离副本含 27 作品、38 历史、27 任务、21 素材、17 音源；禁用副本云端配置，不改用户数据，不复制媒体。旧版 state.get 中位约 114.74 ms，新版首轮约 48.94 ms；新建助手会话约 126.36 → 51.22 ms。首轮并发回归存在机器负载，不据此承诺固定启动倍数。
- 首次数据库升级有一次性成本；不把服务 ready 时间等同窗口完全可交互时间，也不把页面挂载测试当成本机模型推理测试。

## 数据兼容

定制已发布迁移 1–6 保持不变，官方规范化追加为第 7 步。官方版本 2 与定制版本 2 按是否存在音源表区分。迁移在事务内执行，失败回滚，升级前保留数据库副本。

真实数据库只读副本升级检查保留全部记录键；五张定制表逐行字节一致。4 条旧作品及 2 条设置按官方规则更新。隔离测试删除云端密钥，并允许服务重新创建本机 API 凭证；未把这些测试副本上传。

## 验证说明

完整 Go 竞态测试通过，新增快照隔离、迁移兼容/回滚、SSE 增量与投影保护回归。前端类型检查与构建通过；首轮 lint 发现原定制的两个闪光图标违反新版规则，已替换。

首轮全量浏览器 160 项中 158 项通过：一项发现编曲版本误显示歌词播放入口，已修复；另一项原生消息测试错误共享可变对象，已改为真实传输的独立快照，不放宽原断言。最终复验、打包、安装和 GitHub 附件核对结果记录在随包 VALIDATION 文件。

官方歌词对齐模型约 1.3 GB，本轮未额外下载进行完整真实歌曲推理；其请求映射、数据保存和界面以自动化回归验证。Linux/macOS 源码保留上游实现，本机交付与安装验证平台为 Windows。既有 AI 模型的乐器身份、音域、奏法和试听限制保持原样。
